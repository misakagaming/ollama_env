It provides methods like AddSwipeListener(swipelistener), Remove Swipe Listeners (removes a listener by reference) which add or remove listeners from set and PrintListeners() method is used print all registered swipe listners' Names at end of execution respectively, to demonstrate the functionality mentioned above.
